# Cars

Управление
--------------------------------
- M — начать/остановить выезд машины; если пандус закрыт, он сначала автоматически откроется.
- O — открыть/закрыть пандус вручную (до начала выезда машины).
- H — включить/выключить фары.
- R — вернуть сцену в исходное состояние.
- T — включить/выключить текстуру на трейлере.
- L — включить/выключить освещение.
- A — включить/выключить альфа-наложение прозрачных стёкол и света фар.
- F — перенести источник света в позицию камеры.
- G / G+ЛКМ — управление источником света, предусмотренное исходным шаблоном.
- Мышь / колесо — управление камерой, предусмотренное исходным шаблоном.

Соответствие требованиям задания
--------------------------------
- Объекты из геометрических фигур: трейлер, кабина, пандус и автомобиль собраны из параллелепипедов, сфер и цилиндров.
- Материалы: блестящий красный корпус, металл трейлера, резина колёс, стекло и светящиеся фары.
- Освещение: используется Light из стартового шаблона; режим переключается клавишей L.
- Простая текстура: trailer_logo.png полностью натягивается на одну боковую грань трейлера.
- Альфа-наложение: прозрачные стёкла автомобиля и световые конусы фар; режим переключается клавишей A.
- Интерактивность: пандус, движение автомобиля, фары, текстура, свет и прозрачность управляются с клавиатуры.
